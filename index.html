01Install

Polygraph runs on Blender 4.2 and later, on Windows, macOS and Linux.

  1. Download the Polygraph zip. Keep it zipped.
  2. In Blender, open Edit > Preferences > Get Extensions.
  3. Open the menu at the top right of that page, choose Install from Disk and pick the zip.
  4. In the 3D Viewport, press N and open the Polygraph tab.

To update, install the new zip the same way. Your settings and your own profiles stay where they are.

Free, Pro and Studio share one extension id, so installing one replaces the other. That's on purpose: you never run two copies side by side.

On a Mac, Safari unzips downloads by itself, which leaves a folder Blender can't install. Download with another browser, or turn off Open safe files after downloading in Safari > Settings > General. If it's already unzipped, compress the folder again in Finder and install that.

02First run

The top panel of the Polygraph tab shows the scene's triangles, its engine vertices and its objects. The line above the numbers says what is counted, and each part of it is a menu:

Scope
Visible objects, the whole view layer (hidden ones included), the selection, or one collection and its children.
Evaluation
Viewport counts the geometry as the viewport shows it, modifiers and Geometry Nodes included. Base Mesh counts it without modifiers.
Target
glTF, Unity or Unreal Engine. It decides how vertices are counted. glTF is the default, and it is also the right choice for Godot, three.js and other web loaders.

Pick a budget from the menu under the numbers, or choose Custom and type your own limits. From then on the panel gives a verdict, worked out from the single worst limit rather than a blended score:

Within budget Close to the limit Over budget

Close starts at 85% of a limit, unless the budget says otherwise. Meta Quest budgets, for example, start warning earlier.

03The panels

Polygraph
The verdict, the budget, the scene totals and Where to Cut.
Viewport
Four switches: Stats (the readout in the viewport), Heatmap, In Camera and Pixel Preview, each with its options underneath.
Objects
Every object, mesh, collection or LOD chain, with the columns you choose: triangles, engine vertices, budget used, faults, texel density, screen coverage, triangles per pixel, or the change since a snapshot. Click a column to sort by it.
Materials
Draw calls, material slots, texture memory and the largest textures.
Active Object
The selected object's figures, and how much each cause adds to its engine count.
Checks
The 21 mesh checks, with buttons to mark the faults on the object or select them in Edit Mode.

Two preferences put Polygraph elsewhere too: Total in the Viewport Header shows the scene's triangles in the 3D Viewport's header, and Panel in Scene Properties repeats the panels in the Scene tab of the Properties editor.

04Engine counts

Blender stores one vertex for each corner position. A game engine needs one for every different normal, UV and colour that meets at a corner, so it splits vertices along UV seams, sharp edges and flat-shaded faces. The default cube is 8 vertices in Blender and 24 in any engine.

Polygraph counts the way each target imports:

glTF
Vertices as Blender's own glTF exporter writes them.
Unity
Vertices of a model imported into Unity. The Tangents option counts the vertices Unity adds for tangents; turn it off if you import with Tangents set to None.
Unreal Engine
Vertices of a static mesh, with Nanite off.

When a figure can only be estimated, it carries ≈ in front. A mesh over 65,535 engine vertices gets a note that it needs 32-bit indices, which some mobile targets don't like.

The Active Object panel breaks the count down by cause, so you can see which seam or sharp edge is costing what. On a very dense mesh this takes a moment, so press Explain Vertex Count to work it out.

Your own budgets

Type limits into the Custom budget, or keep the current ones with Save as Profile. Your profiles live in Blender's folder for extension data; Open Your Profiles Folder in the preferences, under Budget Profiles, takes you there. A file you add, change or delete shows up in the menu within a second, with no restart. Where one of yours has the same name as a shipped one, yours wins.

A profile looks like this. Every field is optional apart from at least one limit.

{
  "name": "Our mobile game",
  "note": "Agreed with the lead on 3 March.",
  "near": 0.85,
  "scene":  { "triangles": 250000, "draw_calls": 120, "texture_memory_mb": 256 },
  "object": { "triangles": 8000 },
  "classes": [ { "match": "hero_*", "triangles": 30000, "distance": 3 } ],
  "textures": { "largest": 2048, "power_of_two": true }
}

Limits can be set on triangles, vertices, objects, draw_calls, material_slots, materials, texture_memory_mb, bones and skinned_meshes. distance is the metres an object is usually seen from, and display takes a screen's height and fov, or a headset's pixels_per_degree.

Bringing budgets in Pro

Import Budget from CSV and Export Budget as CSV move limits to and from a spreadsheet. Import Khronos Audit Profile reads a profile written for the Khronos glTF Asset Auditor.

Budgets for a whole team Studio

Put profiles in a folder named polygraph_profiles next to the project's .blend files, or in any folder above them. Everyone who opens a file under it gets the same budgets, and so does the command line check.

06Mesh checks

21 checks run on every object in scope. Faults are things an engine or a printer will object to. Notes describe the mesh and are often fine, depending on what it is for. Mark on Object draws what a check found in the viewport, and Select in Edit Mode selects it. Check Thresholds sets the merge distance, the smallest face area, the needle angle and the sharp angle.

07Where to Cut and What If

Where to Cut, at the bottom of the top panel, lists the changes that would save the most, largest first. Each one names its cause, the share it would save and what to do about it, and the arrow beside it selects the objects it's about. Free shows the top three; Pro shows them all.

What If Pro lets you assume something about the selected objects before you touch them: that they're gone, that they switch to their next LOD, or that their triangles are capped. Every figure and the verdict then read as if you had. Take Back Every Assumption clears them. Nothing in the file changes until you make the edit yourself.

Edit receipts Pro price each edit of the active object: the triangles and vertices it added or saved.

08Player's viewPro

Budgets for headsets and phones are stated per frame, so what matters is what the player can see.

In Camera
Judges only what the active camera can see, once what stands in front of it is taken away. The Objects list gains screen coverage and triangles per pixel.
Pixel Preview
Shows a model at the size the player will see it, in pixels, for a flat screen (its height and field of view) or a headset (pixels per degree).
Heatmap
Colours every object by triangles. Pro adds share of the scene, budget, triangle density, pixels per triangle, overdraw, and triangles per camera pixel, where objects the camera never sees are hottest.
Measured
LOD switch distances, overdraw, an estimate of ray tracing cost and the cost of shadows, each measured from the scene rather than guessed.

09Reports and snapshots

Export Report writes an HTML report you can send to anyone: the verdict, every limit, the heaviest objects, the textures and Where to Cut. Pro adds JSON, CSV and Markdown, and Studio puts your studio's name and logo on it.

Take Snapshot Pro keeps the current figures, and Compare With Snapshot shows what changed since, line by line. Copy Summary Pro puts a short text summary on the clipboard for a chat or a ticket.

11Command line and PythonStudio

Polygraph measures a .blend file the same way from the panel, from a build script and from Python, and all three write the same report. Nothing is sent anywhere, and nothing in the file is changed.

blender -b level.blend --command polygraph check --profile meta_quest_3 --target UNITY --junit results.xml
blender --command polygraph profiles
Exit codeMeaning
0Within budget, or no budget set
1Over budget. With --strict, close to a limit counts too
2Something went wrong: an unknown profile, scene or target, or a file that couldn't be written
OptionWhat it does
--profile IDJudge against this budget. It can also be the path of a profile's JSON file, or of a Khronos glTF Asset Auditor profile. NONE judges nothing. Without it, the scene's own budget is used
--target UNREAL|UNITY|GLTFCount vertices as this engine does. Without it, the scene's own target
--scene NAME, --view-layer NAMEMeasure another scene or view layer
--strictFail when a limit is close as well as when it's passed
--no-checks, --no-materialsLeave out the mesh checks, or draw calls and textures, to save time
--json, --csv, --html, --markdown PATHWrite that kind of report
--junit PATHWrite JUnit results: one test for each scene limit and each object with a limit

Polygraph has to be installed and enabled in the Blender that runs the command. A build machine can give Blender a folder of its own with BLENDER_USER_RESOURCES, install Polygraph there once, and leave everyone else's setup alone.

Python

import bl_ext.user_default.polygraph.api as polygraph

result = polygraph.evaluate()
if result["budget"]["state"] == "OVER":
    for entry in result["objects"]:
        if entry["verdict"] and entry["verdict"]["state"] == "OVER":
            print(entry["name"], entry["triangles"])

evaluate() returns the report as a dictionary, profiles() lists every budget, and write_report(path) writes a report whose kind follows the file extension: .html, .json, .csv, .md, or .xml for JUnit. The module path depends on the repository Polygraph was installed from; user_default is the one Blender uses for extensions installed from disk.

The report's schema is polygraph-report/1. Fields are only ever added to a version, never renamed, removed or given another meaning.

12Privacy

Polygraph works offline. Nothing about your files ever leaves your computer.

The Gumroad and Superhive builds can check for a newer version. The check is off until you switch on Check for Updates in the preferences, and it also waits for Blender's own Allow Online Access. Once a day it reads one small file on this site that names the latest version. The request carries nothing about you or your files, only the name Polygraph. The extensions.blender.org build has no update check at all, because Blender updates it for you.

  • A verdict against 32 budgets (5 in Free), or limits you type in
